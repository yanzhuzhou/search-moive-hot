Playwright 登录操作指南

  1. 安装 Playwright（一次性）：pip install playwright && playwright install chromium
  2. 在终端执行登录引导：python -m price_compare.cli login jd（jd/taobao/pinduoduo）
  3. 弹出浏览器 → 扫码/账号密码登录 → 登录完成后回到终端按回车
  4. cookie 会保存在 .playwright_cookies/ 下
  5. 本页面选「Playwright 真实抓取」→ 开始采集即可看到真实价格
⚠ cookie 有效期 7-15 天，过期后需重新 login 一次
